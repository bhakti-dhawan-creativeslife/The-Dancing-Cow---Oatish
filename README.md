# Dancing Cow — Oatish

A creative brand concept built around one simple question:

If no cow is needed to make oat milk, why should the cow be working?

## The Idea

The Cow Is Off Duty.

Instead of giving the cow another personality, the concept gives the brand a point of view around freedom, playfulness and conscious choice.
